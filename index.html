Problem

쇼츠에서 쇼핑이 불편한 이유

YouTube Shorts를 사용하면서 직접 느꼈던 불편함에서 출발했습니다. 제품 스티커가 시청을 방해하고, 관심 있는 제품을 저장할 방법이 없다는 점에 주목했습니다.

01

😤

"쇼츠 보는데 스티커가 화면을 가려요"

쇼핑 스티커가 Shorts 화면 위에 고정 배치되어 있어 영상 콘텐츠를 가리거나 시청을 방해합니다. 사용자가 스티커 위치를 옮기거나 제거할 수 없어 불편해도 그냥 감수해야 합니다.

02

😰

"스티커, 눌러도 되는 건지 누르면 어디로 가는 건지 모르겠어요"

스티커를 클릭하면 아무런 안내 없이 바로 외부 구매 사이트로 이동합니다. 어디로 연결되는지 사전에 알 수 없고, 하단의 "제휴사" 버튼도 기능을 예측하기 어려운 레이블이라 클릭을 망설이게 됩니다.

03

🤔

"이 제품이 영상 어디서 나왔는지 모르겠어요"

바텀시트에 여러 제품 정보가 나열되지만, 각 제품이 영상의 어느 시점에 등장하는지 확인할 수 없습니다. 제품과 영상 장면의 연결이 끊겨 있어 제품에 대한 신뢰도와 구매 의욕이 떨어집니다.

04

😩

"영상 말고 제품만 저장할 방법이 없어요"

YouTube Shorts에서 제품 스티커를 통해 상품을 확인할 수 있지만, 관심 있는 제품만 따로 저장하는 기능은 없습니다. 나중에 다시 보려면 해당 Shorts 영상을 직접 찾아야 하는 번거로움이 있습니다.

Insight #1
스티커 제거 방식이 직관적이지 않아 포기로 이어짐
X버튼을 찾지 못하거나 찾아도 드래그까지 해야 해서 그냥 넘기게 됨. 제거 인터랙션 자체를 단순화해야 함.
⚠️
Insight #2
스티커 클릭 루트가 예측 불가능해 신뢰가 무너짐
"제휴사" 버튼의 의미를 이해한 참가자가 없었고, 스티커 클릭 시 바로 외부로 넘어가는 구조가 불안감을 만듦. 바텀시트를 기본 경로로 설계해야 함.
✨
Insight #3
제품과 영상의 맥락이 연결될수록 신뢰도와 구매 욕구가 높아짐
태그된 제품 칩과 타임스탬프에 강한 긍정 반응. 사용자는 제품이 영상의 어느 장면에서 나왔는지 알고 싶어하며, 이 연결이 있을 때 신뢰와 관심이 높아짐.

Design Decision

디자인 결정과 그 이유

01

스티커 위치를 사용자가 직접 제어할 수 있게

크리에이터가 설정한 스티커 위치가 Shorts 화면 우측 패널의 좋아요, 공유 등 액션 버튼들과 겹쳐 오클릭이 발생하는 경우가 많았음. 사용자가 직접 드래그로 위치를 옮기거나 제거할 수 있도록 하되, 특정 영역 밖으로는 배치되지 않도록 제한을 두어 의도치 않은 클릭을 방지함.

02
UT 결과 반영

스티커 클릭 시 바텀시트를 기본 경로로

기존에는 "제휴사" 버튼을 눌러야 바텀시트가 열렸고, 스티커 자체를 클릭하면 바로 외부 사이트로 이동하는 구조였음. UT에서 대다수의 참가자가 이 구조를 예측하지 못했고 불안감을 만든다는 걸 확인함. "제휴사" 버튼을 없애고 스티커 클릭 시 바텀시트가 바로 올라오도록 구조를 변경함.

03
UT 결과 반영

스티커 삭제 인터랙션 수정

초기 디자인에서는 스티커를 꾹 누른 후 우측으로 드래그하면 삭제되는 방식이었으나 UT에서 불편하다는 반응이 다수였음. YouTube에서 이미 익숙한 점점점(⋮) 더보기 아이콘 방식을 채택해, 누르면 바텀시트가 올라오며 "닫기"를 선택할 수 있도록 수정함.

04

YouTube 기존 흐름 위에 저장 기능 설계

새로운 기능일수록 사용자가 이미 익숙한 패턴 위에 얹히도록 설계하는 것이 중요하다고 판단함. YouTube의 기존 영상 저장 플로우와 유사한 방식으로 제품을 저장하면 "내 제품(My Products)" 카테고리에 담기도록 설계함.

05

태그된 제품 뱃지 + 타임스탬프로 영상-제품 연결

바텀시트에 제품이 여러 개 나열될 때 어느 것이 영상에 실제로 등장한 제품인지 구분이 안 됐음. "태그된 제품" 뱃지와 타임스탬프를 추가해 영상 속 제품을 명확히 구분하고, 해당 제품이 등장하는 시점으로 바로 이동할 수 있도록 함.

06
UT 결과 반영

Related Videos(관련 영상)로 제품 관련 영상 탐색 플로우 추가

바텀시트에서 제품을 확인한 후 해당 제품과 관련된 다른 Shorts나 Videos를 바로 탐색할 수 있는 플로우가 없었음. Related Videos 버튼을 추가해 누르면 해당 제품과 관련된 영상 목록 페이지로 이동하도록 설계함.

07

My Products 목록에서 View, Shorts, Videos로 연결

저장된 제품 목록에서 해당 제품의 상세 페이지(View), 관련 Shorts, Videos로 바로 이동할 수 있는 플로우를 설계함. 저장 후 재탐색 경험을 개선해 제품을 다시 찾는 번거로움을 줄임.

08

상품 정렬 기능 추가

My Products에 저장된 제품들을 사용자가 원하는 순서로 직접 정렬할 수 있는 기능을 추가함. 관심도나 구매 우선순위에 따라 제품을 재배치할 수 있어 저장 후 재탐색 경험을 개선함.

Reflection

배운 것과 다음에 할 것

배운 점

실무에서는 UX 리서처와 프로덕트 디자이너의 역할이 구분되거나, 리서치부터 디자인까지 전 과정을 깊이 있게 다루기 어려운 경우가 많습니다. 이번 프로젝트를 통해 사용자 인터뷰, 어피니티 매핑, UT, 디자인까지 정석적인 UX 프로세스 전 과정을 직접 경험했고, 데이터와 리서치가 디자인 결정에 얼마나 중요한 역할을 하는지 몸소 배울 수 있었습니다.

인터뷰에서 배운 점

인터뷰를 처음 진행하면서 질문 설계의 중요성을 깨달았습니다. 디자인 의도를 가지고 질문을 던지다 보면 사용자가 유도된 답변을 하게 될 수 있다는 것을 느꼈습니다. UT 진행 과정에서 질문을 수정해가며 개선했고, 다음에는 처음부터 더 중립적인 질문 설계를 할 수 있을 것 같습니다.

향후 개선 방향

전 과정을 폭넓게 다루다 보니 특정 포인트를 더 깊이 파고드는 데 한계가 있었습니다. 다음에는 리마인드 기능이나 Shorts 썸네일에서 제품 스티커 유무를 미리 확인할 수 있는 기능 등 더 고도화된 경험까지 설계해보고 싶습니다.

아쉬운 점

프로젝트 진행 당시 제품 스티커 기능이 한국에 출시된 지 얼마 되지 않은 시점이라 기능을 인지하고 있는 참가자를 모집하는 것 자체가 쉽지 않았습니다. 지금 시점이었다면 기능에 더 익숙한 사용자들로부터 더 풍부한 인사이트를 얻을 수 있었을 것 같습니다.
